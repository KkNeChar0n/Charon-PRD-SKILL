# PRD-SKILL

一组 Claude Code 技能插件，用于生成专业的 PRD（产品需求文档）。包含 4 个 skill：

| skill | 作用 |
|-------|------|
| `/prd <需求>` | 生成 **HTML 格式** PRD（含浏览器内联编辑器，点编辑后可点击修改、一键保存覆盖原文件） |
| `/prd-feishu-init` | 一次性初始化飞书自建应用凭证，存于 `~/.prd-feishu/config.json` |
| `/prd-feishu <文档URL> <需求>` | 把 PRD 写入**用户预先创建**的飞书文档（设链接共享「组织内可编辑」即可） |
| `/prd-feishu-batch <目录> <父节点URL>` | 批量把目录下 `PRD_*.html` 写入飞书知识库父节点下的预建子文档（按标题自动匹配） |

## 特性

### `/prd`（HTML 版）

- 结构化的 PRD 文档：产品架构图（思维导图）、功能清单、状态机图（SVG 泳道图）、原型图、逻辑补充
- 粘贴到飞书 / 语雀 / 石墨 / Notion 等编辑器后，表格自动渲染为目标平台原生样式
- 完全自包含的单 HTML 文件，无外部依赖
- 内嵌**内联编辑器**：默认只读（Cmd+A 全选正常），点右上角「🖊 编辑」进入修改态，「💾 保存」用 File System Access API 直接覆盖原文件

### `/prd-feishu`（飞书版，写入用户预建文档）

- 用户**先**在飞书任意位置（云盘 / 知识库）建一个空 docx，设链接共享为「**组织内获得链接的人可编辑**」
- 把文档 URL 传给 skill，skill 清空原内容后写入完整 PRD
- 正文使用飞书**原生块**（标题 / 段落 / 表格 / 列表 / 引用 / 代码块 等）
- 原型图渲染为 PNG（PIL 自动裁底部白边）后上传为飞书图片块
- 彩色徽章用纯文本标注（如「● 已验证（绿）」），保持飞书内文字可搜索
- 文档归属和位置完全由用户控制，应用零空间权限

### `/prd-feishu-batch`（飞书批量版）

- 输入「本地目录」+「飞书知识库父节点 URL」，自动按标题匹配本地 `PRD_*.html` 与子节点
- 展示匹配结果让用户确认后串行写入（含频率限制处理）
- 用于一次开多个迭代需求文档的场景：在飞书里先建好 N 个空节点，本地写好 N 份 HTML，一条命令全部入库

## 文档结构（两个生成 skill 共享）

```
1. 需求名称
2. 需求目标
3. 需求简述
   3.1 产品架构图（思维导图）
   3.2 功能清单
4. 需求详述
   4.x.1 状态机（SVG 泳道图，仅有真实业务状态流转时画）
   4.x.2 原型图（筛选区 / 列表区 / 表单区 + 视觉原型设计图）
   4.x.3 逻辑补充（仅复杂业务逻辑时写）
```

## 使用方法

### 生成本地 HTML 格式 PRD

```
/prd 电商平台订单管理系统
/prd 电商平台，支持商品管理、购物车、下单、支付、发货、退款
```

生成 `PRD_<名称>.html`，浏览器双击打开即可阅读 / 编辑 / 一键保存。

### 配置飞书接入（仅需一次）

```
/prd-feishu-init
```

按引导填写飞书自建应用的 App ID + App Secret（创建步骤见 skill 内提示），凭证保存到 `~/.prd-feishu/config.json`。

### 写入飞书云文档 PRD（单份）

第 1 步：在飞书里新建一个空 docx 文档，分享 → 链接共享 →「组织内获得链接的人可编辑」，复制 URL。

第 2 步：

```
/prd-feishu https://xxx.feishu.cn/docx/{id} 电商平台订单管理系统
# 或 wiki 节点：
/prd-feishu https://xxx.feishu.cn/wiki/{token} 电商平台订单管理系统
```

skill 会：
1. 生成 PRD 内容草稿（与 `/prd` 同结构）
2. 把视觉原型图渲染为 PNG（用本地 Chrome headless + PIL 自动裁白边）
3. 调用飞书 API：清空目标文档 → 转换 Markdown → 插入嵌套块 → 上传图片素材 → 绑定图片块
4. 提示 URL 让你打开飞书复查

### 批量写入飞书（多份）

```
/prd-feishu-batch /path/to/prd-folder https://xxx.feishu.cn/wiki/{parent_node_token}
```

需要前置：父节点（或所在知识库）已设链接共享「组织内可编辑」；父节点下已建好 N 个空 docx 子节点，标题与本地 `PRD_*.html` 文件名能对得上。skill 会自动列出子节点、做模糊匹配、展示对应关系让你确认后串行写入。

## 费用说明（飞书）

飞书开放平台 OpenAPI 调用本身**免费**：
- 基础免费版：每月 1 万次调用额度（2026 年 5 月限时 100 万次/月）
- 单份 PRD 大约消耗 20~35 次 API 调用（创建文档 / 转换 / 上传图片 / 插入块 / 绑定图片）
- 实测每月可生成约 300~500 份 PRD，绰绰有余
- 超量后调用失败（HTTP 429），需联系企业管理员升级飞书版本
